# 資料字典（jade.db）

jade.db 由 `build_db.py` 從 `jade_data.numbers`（也支援 .xlsx）重建；重建時保留 `staging` 與 `query_log`。共 9 張表。

## knowledge　知識卡（jade_data「知識卡」表）

| 欄位 | 試算表欄名 | 說明 | 範例 |
|---|---|---|---|
| id | 編號 | K＋3 位數字，給了就不改 | K001 |
| category | 分類 | 七大主題之一（下拉選單）：認識翡翠、品質判斷、真假處理、證書鑑定、選購價格、款式寓意、配戴保養 | 真假處理 |
| question | 問題 | 卡片標題 | B 貨是什麼？ |
| answer | 答案 | 用自己的話改寫 | B 貨是先用強酸… |
| caution | 注意事項 | 顯示成黃色提醒 | 要求附鑑定證書… |
| keywords | 關鍵字 | 用「、」分開，搜尋會比對 | B貨、灌膠、酸洗 |
| hot | 熱門 | 是＝1、否＝0；標為熱門的卡出現在知識搜尋頁的常見問題 | 1 |
| status | 狀態 | 草稿／已審核；網站只顯示已審核 | 已審核 |

## sources　來源（jade_data「來源」表）

| 欄位 | 試算表欄名 | 說明 |
|---|---|---|
| id | 編號 | 等級＋3 位數字：SA001（A 級）、SB001（B 級）、SC001（C 級） |
| name | 名稱 | 資料名稱 |
| org | 機構或作者 | 可空白；論文寫「作者（《期刊》年份，卷(期):頁）」，網站會顯示 |
| type | 類型 | 官方機構、鑑定機構、珠寶公會、學術資料、書籍、品牌或鑑定師 |
| level | （自動） | 依「選項」表換算：A 官方；B 鑑定機構、公會、學術、書籍；C 品牌或鑑定師 |
| url | 網址或書名 | 書籍填書名 |
| accessed | 存取日期 | 2026-10-28 格式 |
| method | 取得方式 | 爬蟲／API／人工摘錄。經 OpenAlex 找到的論文：來源寫期刊與作者，取得方式填 API |

## knowledge_sources　知識 ↔ 來源（程式自動）

由知識卡的「來源編號」（SA001、SB004）拆開產生，一張卡可引用多個來源。

## synonyms　同義詞（jade_data「同義詞」表）

| 欄位 | 說明 |
|---|---|
| term | 使用者說法（灌膠）；試算表一格可寫多個，用「、」分開，建庫時拆成多筆 |
| canonical | 標準詞（B貨），一個說法只能對應一個標準詞 |

建庫與搜尋時會先全形轉半形（Ａ貨 → A貨）；單一個字的說法只有整句就是那個字才算，避免「到底」誤抓「底」。

## recommend_rules　選款規則（jade_data「選款規則」表）

| 欄位 | 說明 |
|---|---|
| id | R＋3 位數字 |
| budget、item、use_case | 預算、品項、用途（日常配戴、婚嫁、紀念、祈福護身、收藏）；同一組只能一條；預算或用途可填「不限」當通用規則。25 條「品項×用途」規則都填預算「不限」，預算的差別交給「選款提醒」的預算提示 |
| suggestion1–3 | 建議方向 |
| caution | 選購重點 |
| source_ids | 來源編號 |

## recommend_tips　選款提醒（jade_data「選款提醒」表）

| 欄位 | 試算表欄名 | 說明 |
|---|---|---|
| kind | 類型 | 預算、對象或年齡 |
| option | 選項 | 例如 8,000 以下、家人親戚、長者（65 歲以上） |
| item | 品項 | 空白＝適用全部品項；有填的只在選到該品項時出現（例如 嬰幼兒＋耳環） |
| tip | 提醒 | 一句話，顯示在建議方向下面 |
| source_ids | 來源編號 | 和規則的來源一起列在參考資料 |

對象、年齡不寫成規則：組合太多（4 × 5 × 6 × 7 × 7），改成各寫一句提醒，和主規則一起顯示。
預算也用同樣做法：用途規則 25 條（品項 × 用途）＋預算提示 20 句（品項 × 預算）＝45 則，100 種預算×品項×用途組合全部同時有用途建議和預算提醒。

## staging　爬蟲與 API 暫存（crawler.py、api_fetch.py 寫入）

url、title、content（300–500 字段落）、fetched_at、status（pending）、authors、citation、summary_zh（中文精簡翻譯）、method（取得方式：爬蟲／API（OpenAlex）／API（維基百科））。人工審核後改寫進 jade_data，不會直接上網站。維基百科只當線索：知識卡改引用條目最後一段列出的原始出處。

## query_log　查詢紀錄（網站自動，只給自己看）

ts、query、hits（命中筆數）、filters。雲端網站重啟後會清空，需要時從網站側邊欄下載。

## knowledge_fts　全文索引（程式自動）

FTS5 trigram 索引（問題、答案、注意事項、關鍵字），3 個字以上的詞用它搜尋。
